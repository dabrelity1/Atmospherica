## 2024-07-26 - Java Version and ForgeGradle Cache Corruption
**Learning:** ForgeGradle for Minecraft 1.20.1 requires Java 17 and will fail cryptically if compiled under Java 21 initially. If a Java 21 Gradle daemon attempts to download or process mapping artifacts, the `~/.gradle/caches/forge_gradle` directory becomes corrupted with incomplete decompilation runs, leading to missing packages (`net.minecraft.client.main`) or unresolved dependencies (`1.20.1-47.3.0_mapped_official_1.20.1`). Switching to Java 17 later does not resolve the issue if the cached artifacts remain.
**Action:** When working on this specific repository, immediately set the default system Java/Javac to version 17 using `apt-get` and `update-alternatives`. If build errors indicating missing symbols or unresolved forge mappings occur, run `gradle --stop` and `rm -rf ~/.gradle/caches/forge_gradle` to clear the poisoned cache before retrying the build under Java 17.
