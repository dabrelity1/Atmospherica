## 2024-07-02 - Eliminate Object Allocations in Frame Render Loops via Bit-Packed Arrays
**Learning:** High-frequency rendering loops (`ParticleManager.render`) using `List.sort()` with custom comparators allocate numerous short-lived `Vec3` objects and boxed `Double` primitives on every single frame comparison, creating tremendous GC pressure and severe stuttering in Java 17 / Minecraft Forge.
**Action:** Replace `List.sort(Comparator)` with primitive array sorting (`Arrays.sort`). Calculate the squared distance manually avoiding `Vec3` creation, then pack the `float` distance into the high 32 bits and the list index into the low 32 bits of a primitive `long[]` array. Because physical distances are positive, their IEEE 754 float bit representation sorts perfectly sequentially like integers. Extract via `Float.intBitsToFloat((int)(val >> 32))`. This achieves zero-allocation sorting on the hot path.
